# Logbooks

One file per working session or experiment, named `YYYY-MM-DD-<topic>.md`, newest
work at the bottom of the file. Each entry records:

- **Goal**: what we were trying to find out or change.
- **Setup**: model, adapter, dataset/split, prompt format, sampling, command.
- **Results**: scores and a few example outputs, with where the predictions live.
- **Notes / decisions**: what we concluded and what to try next.

Keep scores comparable: say which split and prompt format every number comes from.
